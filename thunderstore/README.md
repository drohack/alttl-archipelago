# A Little to the Left Archipelago

An [Archipelago](https://archipelago.gg) multiworld randomizer for
[A Little to the Left](https://store.steampowered.com/app/1629520/) (Steam,
Windows).

Your run is a track of puzzles, many of them procedurally generated. Its
solutions, the groups you tidy and the credits are checks; Puzzle Packs, the
game's mechanics (Stacking, Rotating, Drawer and the rest), Skips and Hint
Pages are items, and any player in the multiworld can be the one holding
yours.

## You also need

- A multiworld to join. Whoever generates the seed needs `alttl.apworld`, and
  every player a yaml; both are on the
  [GitHub releases page](https://github.com/drohack/alttl-archipelago/releases).
  Use the release with the same version as this mod.
- The base game on Steam. Both DLCs are supported and off by default.

## Install

Install with r2modman or Thunderstore Mod Manager; BepInEx comes with it.
Launch the game from the mod manager. The first launch is slow while BepInEx
generates its files.

## Connect

The main menu gains an **Archipelago** entry. Fill in the server (`host:port`
from the room page), your slot name exactly as in your yaml, and the password
if the room has one, then press **Connect**. With Auto-connect on, the game
rejoins your multiworld every launch.

A randomized run keeps its own save: your campaign save is never written to.
